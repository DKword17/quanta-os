# 离子阱量子芯片架构

## 技术原理

将单个离子（通常是 Yb⁺）囚禁在 Paul 阱中，利用离子的基态 |0⟩ 和亚稳态 |1⟩ 作为 qubit。通过激光束或微波驱动实现门操作。

## 核心特性

- **全连通**：所有离子都可以通过激光束寻址，无需 SWAP
- **超长相干时间**：T2 可达数秒甚至分钟
- **高保真度**：2 量子门保真度可达 99.95%
- **慢速门**：门操作 ~100-300 μs（比超导慢 ~1000x）

## Quanta OS 专用优化

- **Molmer-Sorensen 门** — 多体纠缠门，原生优势
- **全连通映射** — 无需 SWAP，拓扑全联通
- **CCD (Charge-Coupled Device)** — Quantinuum 架构中离子可物理移动
- **激光寻址优化** — AOD 声光偏转器快速跳转
- **复合脉冲** — 补偿激光功率波动

## 运行环境

- 室温操作（离子被囚禁在超高真空中）
- 超高真空: ~10⁻¹¹ Torr
- 激光系统: 多个稳频激光器（369nm, 935nm, 355nm...）
- 控制 FPGA: 激光脉冲时序（ns 精度）
