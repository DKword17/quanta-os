# 光量子计算架构

## 技术原理

光量子计算使用光子作为量子信息的载体。主要有两条路线：

**压缩态路线 (Xanadu, 玻色量子)**
- 使用压缩真空态（squeezed vacuum states）
- 操作 = 线性光学（分束器、相移器、压缩器）
- 测量 = 零差检测（homodyne detection）
- 非通用模型 → 高斯玻色采样（GBS）和特定问题优化

**单光子路线 (PsiQuantum, 图灵量子)**
- 单光子作为 qubit
- 操作 = 分束器网络、融合测量
- 通过 post-selection 实现确定性门
- 室温运行，硅光子集成

## Quanta OS 专用优化

- **qumode → 二进制编码** — 将连续变量映射到 qubit 空间
- **Gaussian 保真度** — 高斯操作（分束器/压缩）的保真度优于非高斯
- **损失容错** — 光子损失的纠错编码
- **融合测量调度** — 最大化簇态生成成功率

## 运行环境

- 室温
- 光纤/波导耦合
- 超导纳米线单光子探测器（SNSPD，需 ~3K）
- 或零差探测器（室温可用）
